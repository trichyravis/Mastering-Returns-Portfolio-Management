# Mastering Returns — Interactive Streamlit Learning Studio

A Mountain Path Academy educational app built in the Ravi1 navy-and-gold
design system. The learning sequence and worked examples are based on the
reference workbook, `1 Updated A Workbook_template_with_examples_and_definitions.xlsx`.

## Educational coverage

- Holding Period Return, income yield and capital gains yield
- Effective annualisation and compounding frequency
- Arithmetic, geometric and harmonic means
- Volatility drag and terminal wealth
- CAGR, cumulative return and endpoint bias
- Probability-weighted expected return and scenario risk
- Simple versus continuously compounded log returns
- Time-Weighted Return versus Money-Weighted Return
- Randomised practice problems with hints and solutions
- Ten-question scored quiz with explanations
- Downloadable formula cheat sheet and learning checklist

## Run locally

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud

1. Upload this folder to a GitHub repository.
2. Select `app.py` as the main application file.
3. Deploy.

The app uses embedded educational illustrations and does not depend on an
external market-data service, making it reliable for classroom demonstrations.

Educational material only — not investment advice.
